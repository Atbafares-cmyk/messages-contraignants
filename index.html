Exercice 4

Quels sont mes messages contraignants ?

0sur 50

Ce que ce test mesure

Ce test identifie lequel des cinq messages contraignants vous pilote le plus : Sois parfait, Sois fort, Fais plaisir, Fais des efforts, Dépêche-toi.

15 minLivret page 12Individuel, en silence

Comment répondre

  • Une seule réponse par proposition.
  • Répondez sans réfléchir longtemps : la première réaction est la plus juste.
  • Il n'y a ni bon ni mauvais profil.
  • Le test est long : 50 affirmations. Prenez votre élan.

Comment lire mes totaux

Le total le plus élevé est votre message dominant : celui qui vous pilote le plus souvent.

Le deuxième total est votre message de rechange, celui qui prend le relais quand la pression monte.

Des totaux proches sur plusieurs colonnes sont fréquents. Cela ne veut pas dire que vous vous êtes trompé.

Et ensuite

Les atouts, les pièges et la permission de chaque message sont dans le livret, à partir de la page 24. Le support reprend la synthèse aux diapositives 32 et 33.
